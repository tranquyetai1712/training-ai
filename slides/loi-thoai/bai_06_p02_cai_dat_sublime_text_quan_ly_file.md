### [01:12 - 02:30] THAO TÁC THỰC TẾ: MỞ THƯ MỤC DỰ ÁN, TẠO FILE MỚI & LƯU CHỈNH SỬA
`[Giao diện Sublime Text mở lên ➔ Bấm File ➔ Open Folder...]`

"Chẳng hạn bây giờ bạn muốn mở một thư mục dự án nào đó để làm việc:
Bạn bấm vào menu **File** ở góc trên bên trái ➔ chọn **Open Folder...**, sau đó chọn thư mục dự án mà bạn muốn mở (ví dụ ở đây tôi chọn thư mục `chi-phi-cong-tac-tho`).

`[Cây thư mục bên trái hiển thị rõ các file trong chi-phi-cong-tac-tho]`  
Như bạn thấy, chúng ta đã mở được toàn bộ dự án này ra! Phần mềm Sublime Text giúp chúng ta quan sát cây thư mục bên cột trái, xem nội dung các file một cách dễ dàng hoặc chỉnh sửa trực tiếp ngay trên màn hình.

**Vậy nếu bạn muốn tạo một file mới bên trong thư mục `chi-phi-cong-tac-tho` này thì làm thế nào?**
1. Bạn chỉ cần nhấp **chuột phải** vào tên thư mục `chi-phi-cong-tac-tho` ở cột bên trái ➔ chọn **New File**.
2. Để lưu file mới này, bạn có thể bấm vào menu **File ➔ Save**, hoặc nhấn tổ hợp phím tắt **`Ctrl + S`**.
3. Ngay lập tức, một cửa sổ chứa đường dẫn thư mục hiện ra để bạn đặt tên và chọn kiểu file. Chẳng hạn ở đây bạn đặt tên là **`test.md`** rồi nhấn **Save**.

`[File test.md xuất hiện ngay trong cây thư mục bên trái]`  
Đấy, vậy là bạn đã tạo ra được file `test.md` ngay trong thư mục dự án! Khi muốn chỉnh sửa nội dung bên trong, bạn cứ gõ hoặc xóa văn bản trực tiếp, sau đó nhấn **`Ctrl + S`** (hoặc bấm vào nút `File ➔ Save`) là phần mềm sẽ tự động lưu lại toàn bộ thay đổi."
