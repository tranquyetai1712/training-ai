# QUY CHUẨN BẢNG THEO DÕI ACTION ITEMS
Khi đọc và xử lý dữ liệu cho bài toán này, bạn BẮT BUỘC tuân thủ các quy tắc sau:

1. Trích xuất đủ 7 cột: STT, Hạng mục công việc, Bộ phận, PIC, Deadline, Mức độ ưu tiên, Trạng thái.
2. Cập nhật trực tiếp vào file `Project_Action_Tracker.xlsx`.
