# QUY CHUẨN TỔ CHỨC THƯ MỤC GOOGLE DRIVE
Khi đọc và xử lý dữ liệu cho bài toán này, bạn BẮT BUỘC tuân thủ các quy tắc sau:

1. Tạo cây thư mục chuẩn cho từng dự án.
2. Ghi lại link thư mục trực tiếp vào cột `Link Google Drive`.
3. Xuất ra file `Danh_sach_du_an_share_updated.xlsx`.
