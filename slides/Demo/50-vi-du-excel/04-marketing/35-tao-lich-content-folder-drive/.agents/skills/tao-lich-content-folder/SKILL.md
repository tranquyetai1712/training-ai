## Bước 1: Đọc lịch bài đăng
Nạp file `content_calendar.xlsx`.

## Bước 2: Tổ chức thư mục

## Bước 3: Cập nhật đường dẫn
Ghi đường dẫn thư mục vào bảng tính và lưu file `Content_Calendar_T11_Updated.xlsx`.
