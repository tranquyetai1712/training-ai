Trụ Cột 4 — Hooks: Vòng Kim Cô Giám Sát AI

Chốt chặn kỹ thuật tự động kiểm soát hành vi của AI — Chặn đứng mọi nguy cơ xóa nhầm file hoặc rò rỉ dữ liệu.

KIỂM SOÁT ĐẦU VÀO
PreToolUse Hook (Soi Trước Khi Chạy)
  • • Can thiệp ngay khi AI chuẩn bị kích hoạt bất kỳ công cụ nào.
  • • Phát hiện lệnh nguy hiểm (xóa thư mục, sửa file cấu hình) và hủy bỏ ngay lập tức.
KIỂM SOÁT ĐẦU RA
PostToolUse Hook (Soi Sau Khi Chạy)
  • • Kiểm tra kết quả ngay sau khi công cụ thực thi xong.
  • • Kiểm tra file đầu ra: Đã chuẩn định dạng UTF-8 chưa? Bảng Excel có chứa công thức hợp lệ không?
🛡️ Sự khác biệt: Rules là 'Biển báo giao thông', Hooks là 'Gờ giảm tốc và Barie tự động'! ZERO RISK

Thực Hành: Cài Đặt Hook Chặn Xóa Dữ Liệu

Biến Antigravity thành trợ lý kỷ luật thép — Tự động từ chối mọi thao tác phá hủy tài liệu kế toán & hợp đồng.

CẤU HÌNH HOOK
File Cấu Hình hooks.json
{ "PreToolUse": [ { "tool": "run_command", "pattern": "(del|rmdir|Remove-Item)", "action": "BLOCK_AND_ASK_USER", "message": "CẢNH BÁO: Thao tác xóa file bị chặn!" } ] }
HIỆU QUẢ THỰC TẾ
AI Tự Động Phanh Gấp
  • • AI nhận diện: Hook chặn lệnh xóa, AI lập tức dừng luồng thực thi.
  • • Hỏi ý kiến bạn: 'Tôi phát hiện file nháp cũ, bạn có chắc chắn muốn xóa không?'
  • • Kiểm soát 100%: Quyền quyết định cuối cùng luôn thuộc về con người!
