Antigravity Remote Control Là Gì?

Giải pháp lái, giám sát và tương tác với AI Agent từ xa trên mọi thiết bị qua nền tảng web bảo mật.

🏢

Cách Làm Cũ (Workstation Bound)

Gò bó vị trí

Phải ngồi trực tiếp trước màn hình máy tính công ty để xem Agent sinh code.

Gián đoạn khi di chuyển

Rời bàn làm việc đi họp, đi ăn trưa là hoàn toàn mù thông tin về tiến độ của agent.

Phê duyệt chậm trễ

Agent dừng lại chờ bấm Approve prompt/lệnh bash, cả luồng công việc bị nghẽn.

⚡

Chuẩn Remote Control (Bất Kỳ Đâu)

Mobile First Web UI

Giao diện web siêu nhẹ trên smartphone, tối ưu hóa cho thao tác cảm ứng.

Theo dõi Realtime

Xem file diff, artifacts, subagent logs trực tiếp trong khi di chuyển.

Phê duyệt 1 chạm

Nhấn 'Approve' hoặc bổ sung prompt cho Agent ngay từ màn hình điện thoại.

Cơ Chế Ghép Nối & Kiến Trúc Bảo Mật

Bật tính năng trong 10 giây và kiến trúc bảo vệ dữ liệu doanh nghiệp đa lớp.

BƯỚC 1

⚙️ Bật Trong Settings

Mở Settings qua phím tắt Ctrl + , (Windows/Linux) hoặc Cmd + , (macOS).

Vào mục Application ➔ gạt toggle Enable Remote Control sang ON.

Hoặc gõ agy --remote-control từ terminal.

BƯỚC 2

📱 Ghép Nối 1 Chạm

Antigravity sinh ngay một mã QR Code bảo mật động trên màn hình.

Dùng camera điện thoại quét mã QR để mở session trên trình duyệt trong 2 giây.

Hoặc truy cập trực tiếp antigravity.google để chọn host active.

BẢO MẬT

🛡️ Chuẩn Doanh Nghiệp

Token Handshake: Mã xác thực dùng 1 lần, chống dò quét IP trái phép.

Không mở Open Port: Hoạt động an toàn sau tường lửa và VPN công ty.

Host Boundary: Toàn bộ source code & secrets lưu tại workstation.

☕ CÀI ĐẶT HỆ THỐNG • LIÊN TỤC KHÔNG GIÁN ĐOẠN

App Settings: Prevent Sleep

Ngăn hệ thống tự động tắt màn hình và đưa PC vào chế độ ngủ khi AI đang sinh mã.

⚡

Bản Chất Cơ Chế Prevent Sleep

Nỗi đau đứt gãy

Hệ điều hành tự Sleep sau 5-15 phút không thao tác ➔ Tiến trình Agent bị ngắt giữa chừng, mất session.

Cơ chế giữ thức thông minh

Antigravity tự động kích hoạt API ngăn chặn sleep ở cấp OS kernel trong suốt thời gian AI viết code.

Tự giải phóng

Ngay khi Agent hoàn thành công việc, máy tính tự động trở lại cơ chế tiết kiệm điện bình thường.

Antigravity > Settings > Application
# System-level Settings Configuration
[X] Prevent Sleep
    Prevent the PC from turning off the screen & sleeping while AI writes code.

Status: RUNNING AGENT (Awake Lock Acquired)

[X] Keep In Menu Bar / Taskbar Tray
    Close button minimizes app to system tray.

[i] Notification Settings
    Managed directly within OS System Settings.
📌 CÀI ĐẶT HỆ THỐNG • THƯỜNG TRỰC & THÔNG BÁO

Keep In Menu Bar & Notifications

Đảm bảo ứng dụng luôn thường trực tức thì và không bỏ sót các tín hiệu hoàn thành của AI.

📌

Keep In Menu Bar / Taskbar Tray

  • ✔ Chống tắt nhầm: Bấm dấu 'X' chỉ đóng giao diện, tiến trình Agent vẫn âm thầm tiếp tục.
  • ✔ Thường trực trên Tray: Neo tại Mac Menu Bar hoặc Windows Taskbar Tray góc dưới màn hình.
  • ✔ Triệu hồi tức thì (Summon): Bấm phím tắt hoặc click khay hệ thống là app bung ra ngay, không phải nạp lại từ đầu.
  • ✔ Bảo toàn ngữ cảnh: Giữ nguyên lịch sử terminal, context diff và các tab công việc.
🔔

Notification Settings (OS-Level)

  • ✔ Nguyên lý quản lý tập trung: Việc bật/tắt thông báo của Antigravity được điều khiển từ Cài đặt Hệ điều hành (Windows / macOS Settings), không nằm trong app.
  • ✔ Thiết lập trên Windows: Start > Settings > System > Notifications ➔ Bật On cho Antigravity.
  • ✔ Thiết lập trên macOS: System Settings > Notifications > Antigravity ➔ Cho phép Banners/Alerts.
  • ✔ Phản hồi thần tốc: Nhận âm báo & popup ngay khi Agent viết xong code hoặc yêu cầu approve.

🛠️ THỰC CHIẾN TÍCH HỢP • NATIVE ANTHROPIC API BRIDGE

Cách Tích Hợp Model Vào Claude Code

Cấu hình ghép nối Ollama với Claude Code qua 2 phương pháp tiện lợi.

Cách 1: Ollama CLI Launch (Khuyên dùng)
# Khởi chạy Claude Code với model mặc định
$ ollama launch claude

# Chỉ định model coding chuyên sâu (Qwen 2.5 Coder)
$ ollama launch claude --model qwen2.5-coder

# Tự động đồng ý & dùng cho CI/CD Script
$ ollama launch claude --model qwen2.5-coder --yes

✔ Connected to local Ollama server (port 11434)
Cách 2: Biến Môi Trường (Environment Variables)
# Cấu hình trên Linux / macOS (~/.zshrc)
export ANTHROPIC_AUTH_TOKEN=ollama
export ANTHROPIC_BASE_URL=http://localhost:11434

# Khởi chạy Claude Code bình thường
$ claude --model qwen2.5-coder

# Cấu hình trên Windows PowerShell
$env:ANTHROPIC_AUTH_TOKEN="ollama"
$env:ANTHROPIC_BASE_URL="http://localhost:11434"
